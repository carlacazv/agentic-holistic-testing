# Planning Poker benchmark

This consumer benchmark checks the public `ljeronimodarocha/planer-poker` repository without modifying it. It covers the highest-risk browser journey identified by the Holistic QA plan: two independent users, hidden voting, real-time convergence, consensus, authenticated CSV export, and the documented password boundary.

The benchmark result is execution evidence, not proof that the product has no defects. Infrastructure failures remain distinct from product assertion failures, and untested host transfer, reconnection, accessibility, and performance risks remain explicit.
